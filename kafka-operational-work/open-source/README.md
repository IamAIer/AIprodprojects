# Open-source implementation

This folder is reserved for the later implementation of the Kafka Operational Assistant using an open-source LLM stack.

Keep the open-source model integration, its application code, configuration examples, infrastructure definitions, and deployment instructions here. The specific model and hosting tools can be selected when this implementation begins. Do not put real credentials, company SOPs, or private Kafka connection details in Git.

Follow the shared workflows in [../docs/architecture.md](../docs/architecture.md) so both implementations support the same Jira and application-team use cases.

Implementation files will be added when work on the open-source version begins.
